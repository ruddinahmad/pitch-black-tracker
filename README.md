# Pitch Black Collection Tracker

A personal, mobile-friendly tracker for the Pokémon TCG: Mega Evolution—Pitch Black (ME05) master set.

## Use the tracker

1. Open the published GitHub Pages website.
2. Select **Edit collection**.
3. Tap a card or use the **+** and **−** buttons to update its quantity.
4. Select **Done** when finished.

Progress saves automatically in the browser on the current device. Use **Backup** to download a copy of the collection and **Restore** to load it on another device.

## Master-set structure

- 84 base cards
- 74 reverse holos
- 36 secret rares
- 194 total collection slots

## Hosting

This is a static website designed for GitHub Pages. In the repository settings, select **Pages**, choose **Deploy from a branch**, and publish the `/ (root)` folder from the `main` branch.

## Card artwork

Card artwork is loaded from Pokémon's official card-image CDN and is not included in this repository. This is an unofficial personal collection tracker. Pokémon and related names and artwork belong to their respective owners.
